# Project-Specific Skills

Put skills here when they apply only to one repository or workflow inside `Codex_mac`.

Recommended pattern:

```text
project-specific/
  <project-name>/
    <skill-name>/
      SKILL.md
```

Do not place third-party source here. Keep reusable personal skills in `codex-skills/custom/` and external snapshots in `codex-skills/third-party/`.
