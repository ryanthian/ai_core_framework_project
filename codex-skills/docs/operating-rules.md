# Codex Skills Operating Rule

Before implementing a non-trivial task:

1. Understand the requirement.
2. Inspect the repository and relevant instructions.
3. Check whether an existing skill can help.
4. Select only relevant skills.
5. Plan the change.
6. Implement.
7. Test.
8. Review.
9. Verify.
10. Summarize changes and unresolved risks.

Never use a skill merely because it is installed.

Skills are capabilities, not mandatory steps.
