# AI-Core Exit Codes

| Code | Meaning |
|---:|---|
| 0 | success |
| 1 | general failure |
| 2 | invalid command or input |
| 3 | validation failure |
| 4 | blocked or human action required |
| 5 | test, review, or verification failure |
| 6 | configuration or environment problem |

JSON output uses the same exit codes and writes only JSON to stdout.
