# Billing Domain Pack

## Glossary

A bill/invoice records an amount due. A payment records value received.

## History

Historical billing records need period, adjustment, backdating, reconciliation, and audit traceability.

## Tests

Cover bill creation, partial payment, adjustment, arrears, backdating, historical views, and reconciliation.

## Document Hints

Use account, bill, payment, adjustment, arrears, meter, billing cycle, and reconciliation as hints only.
